Project Overview

During the summer right before Blue Ghost's historic lunar landing, I worked as a Spacecraft and Avionics Intern on Firefly Aerospace's Blue Ghost program (part of NASA's Commercial Lunar Payload Services (CLPS) initiative).

My primary responsibility was building and programming a high-fidelity simulation testbed to verify lunar lander commands and simulate the spacecraft's thermal control system to validate actual mission operations that would be run.

My Contributions

  • Testbed Development: Built and programmed a high-fidelity testbed* to verify lunar lander commands before deployment
  • Thermal Control System: Created modules to simulate 90+ heater power draws and temperature settings for 120+ temperature sensors
  • Electronics Selection Automation: Automated component selection for heater circuits by web scraping major electronics suppliers' websites to optimize for cost and specifications, improving efficiency and reducing errors
  • Hardware Integration: Designed and implemented a network of Raspberry Pis to control inputs and relays for the simulation
  • Fabrication: Soldered over a thousand electrical connections for the testbed hardware
  • Software: Created a GUI to test temperature sensor set points and monitor system performance
  • Hardware on the Moon: Designed and installed a Firefly plaque* onto the lunar lander, which is now on the Moon!

* project pictures omitted due to confidentiality

Technical Skills Applied

  • Python programming for simulation and control systems
  • Raspberry Pi hardware integration and networking
  • GUI development for testing interfaces
  • Electronics soldering and circuit assembly
  • Thermal system modeling and simulation

Recognition

First intern to receive a Blue Ghost program-wide award for interdisciplinary contributions. This recognition highlighted my work across multiple teams and my impact on mission critical testing infrastructure.

Impact

The simulation testbed I developed was important for pre-flight testing of the Blue Ghost lunar lander's thermal control system. By verifying commands and thermal behavior before the actual mission, the testbed helped lead to a successful mission.

Blue Ghost successfully landed on the Moon, carrying my Firefly plaque... a permanent reminder of my contribution to this historic mission.
