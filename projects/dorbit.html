Project Overview

D-Orbit is a market leader in space logistics and transportation, primarily active in the orbital transfer vehicle market. During my internship, I developed satellite testing infrastructure and a graphical user interface to validate EM component functionality before launch.

My Contributions

I created infrastructure for satellite testing and control, using an Arduino based hardware system and custom Python GUI. The system enabled remote control of satellite components on an electric model replica to validate capabilities before integration into flight hardware.

  • Programmed Arduino to remotely control satellite components through relay and Ethernet shields
  • Developed Python GUI for satellite status monitoring, data management, and dispenser testing
  • Tested satellite capabilities including on/off statuses, failure commands, and basic function tests
  • Shadowed engineers and participated in clean room assembly, testing, and team meetings

Arduino System

Developed embedded Python scripts to connect remote commands to satellite controls.

Hardware Architecture:

  • Arduino Base: core microcontroller for processing commands and controlling outputs
  • Ethernet Shield: network stack for TCP/UDP communication and IP connectivity
  • 4-Channel Relay Shield: high-power switching for components beyond Arduino's digital I/O limits (NO and NC contacts in parallel for increased current capacity)
  • Custom LED Indicators: visual feedback system using LEDs to verify signals

Technical Implementation:

  • Configured fixed IP addressing for reliable network communication
  • Set up webserver to display analog input values (component on/off status)
  • Implemented webclient for UI connection and status display
  • Version controlled all code through GitHub for collaboration

GUI Development

Created a comprehensive graphical interface using PySimpleGUI to manage satellite testing operations.

Key Features:

  • Satellite Status Dashboard: real-time monitoring and control
  • Data Transfer System: bidirectional communication for logging and analysis
  • Proprietary Dispenser Testing: custom testing for payload deployment
  • Command Interface: panel for on/off commands and failure testing
