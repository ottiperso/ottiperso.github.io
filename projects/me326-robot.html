Project Overview

Meet S.E.A.L., a voice-commanded mobile robot that listens, looks, and acts. Built on the bimanual TidyBot++ platform, S.E.A.L. responds to natural language commands to find objects in a classroom environment, navigate to them, and manipulate them with its grippers.

What S.E.A.L. Can Do:

  • Operation Banana Depot (Tasks 1 & 2): S.E.A.L. listens for a spoken command, scans the room using a YOLO vision + Gemini pipeline, navigates to the target object, and either retrieves it back to start or places it in a bowl
  • Operation Bottoms Up (Task 3): S.E.A.L.'s group designed challenge: identify a bottle in the scene, grasp the bottle body with one arm and the bottle cap with the other, twist off the cap, and pour its contents, combining perception, bimanual coordination, and liquid-handling control

Task 1: Object Retrieval

Task 1 required the robot to locate a verbally-specified object (banana), navigate toward it using visual servoing, compute a top-down grasp pose from the object's bounding box and point cloud, grab the object, lift it to a stowed sleep pose, and navigate back to the start position.

Key Steps:

  • Rotate in place to locate the banana in camera field of view
  • Navigate toward object using visual servoing to keep it centered
  • Stop at fixed distance and compute top-down grasp pose from bounding box and point cloud
  • Execute grasp, close gripper, and lift to sleep pose
  • Navigate back to start position

Task 2: Object Placement

Task 2 extended Task 1 with a navigation and deposit sequence. After retrieving the object (banana), the robot rotates to locate a verbally specified destination (bowl), visually servos toward it, stops at distance, extends the arm from the stowed pose to a forward position, and opens the gripper to drop the banana in.

Extra Steps After Task 1:

  • After retrieval, rotate to locate bowl
  • Navigate to bowl using visual servoing
  • Extend arm from sleep pose to forward position
  • Open gripper to deposit object in bowl

Task 2.5: Human Handoff

Task 2.5 generalized Task 2 to a collaborative endpoint. After locating and retrieving the banana, the robot locates a person, navigates toward them, and performs a handoff.

Task 3: Bimanual Bottle Pouring

Task 3 required the robot to navigate to a verbally specified bottle using visual servoing, then use bimanual manipulation to uncap and pour the bottle.

Bimanual Manipulation Sequence:

  • Left arm grasps bottle body from the side using a side approach grasp pose computed from the bottle handle's bounding box and point cloud (red blocks)
  • Right arm grasps bottle cap from the top using a separate top approach grasp pose computed from the cap handle's bounding box and point cloud (yellow block)
  • Right arm twists wrist 180° to unscrew the cap and lifts to sleep pose to remove it
  • Left arm raises and rotates the bottle to pour out contents (beads)

Software Architecture

The TidyBot2 software stack runs on ROS 2 Humble (Ubuntu 22.04) with MuJoCo + RViz as the simulation backend. The system follows an architecture centered on a Brain Node that acts as the orchestrator, communicating with specialized subsystem nodes through published and subscribed topics.

Key Nodes:

  • Brain Node: Task orchestrator that publishes flags and commands to configure downstream nodes
  • Navigator Node: Handles base movement and visual servoing
  • Vision Node: YOLO + Gemini pipeline for object detection and scene understanding
  • Point Cloud Node: Processes depth data for 3D object localization
  • Grasp Planner Node: Computes grasp poses from bounding boxes and point clouds
  • Manipulation Node: Executes arm movements and gripper control
  • Speech Node: Interprets voice commands to initiate tasks
  • MuJoCo Bridge: Simulation interface for testing
  • Hardware Bridge: Real robot control interface

Modular Design:

The architecture was designed to be modular, allowing the same code to serve all three tasks without modification.

Challenges & Future Work

Room for Improvement:

  • Robust grasp pose generation for varied object geometries
  • Lower latency segmentation using lighter weight local models
  • More realistic implementation of Task 3 (wider grippers to accommodate bottle without block handle)
  • Geometric frontier based exploration instead of reactionary navigation

Future Applications:

  • "Barista/Bartender" automation
  • Assistive robotics for elderly / specially-abled persons with object retrieval tasks
  • Precise pouring of medicinal doses
