Project Overview

The 2026 ME 218B project challenged us to design and build a fully autonomous, untethered robot from scratch (max dimensions of 320mm cube at the start of round). The robot had to navigate a 2.4m × 2.4m arena, collect foam balls from dispensers, and deposit them into seesaw buckets to tip the seesaws.

The arena featured IR beacons of different frequencies for calibration, black tape lines for navigation guidance, and a wall dividing the field for competition. The robot needed to autonomously determine which side of the field it was on and navigate with line sensing.

System Architecture:

A dual PIC32 system communicated over SPI to handle sensing, motor control, and decisionmaking, with all code written in C with event-driven software architecture. The Leader PIC handled communication, beacon finding, and line following, while the Follower PIC managed servo actuations for ball dispensing and collection, plus DC motor actuation for the conveyor.

Competition:

Each 2min 18s round was scored by the number of seesaws tipped (goal of tiliting two). Our team completed all project checkpoints and was runner up in the course wide competition.

Technical Implementation

Mechanical & Hardware

Design Constraints:

  • 320 mm cube at start time
  • Under $200 budget
  • ±20mm tolerance on all game parts
  • Built with laser-cut plywood/acrylic, 3D-printed PLA/TPU parts, and off-the-shelf components

Navigation:

  • Two brushed DC motors with 1:50 gearbox (5V, 0.04 N-m torque, 40 RPM)
  • Custom encoder mounts with permanent magnets for position tracking
  • 5 bar line sensor array mounted on robot base
  • Flexible shaft couplers and bearings for smooth drive

Ball Collection:

  • 10+ scooper iterations to handle high friction foam balls
  • 5V continuous rotation servo to scoop in balls
  • Cutouts to pass through conveyor belt ramp
  • Passive alignment cutouts matching dispenser structure

Conveyor System:

  • Raises balls from collection to 2nd level (storage)
  • 0.25" shaft with flexible TPU rollers
  • Sanding belt for high friction
  • 38mm gap between belt and ramp for foam ball compliance

Ball Dispensing:

  • Balls passively sorted into two sides of 2nd level
  • Acrylic floors to reduce friction and prevent jamming
  • Door servos hold balls until dispensing time

Seesaw Arm:

  • Lowers seesaw to enable ball dispensing
  • Reduces robot re-positioning

Electrical & Firmware

Dual PIC System:

  • Leader PIC: Communication leader, drive control, beacon detection, line following
  • Follower PIC: Servo actuation (ball dispensing, collecting, side indicator), conveyor motor control
  • Optimized for minimal SPI communication and parallel testing

Power Distribution:

  • 14V: DC motors
  • 5V: Servos and beacon circuits
  • 3.3V: All logic circuits
  • All ground referenced to PDB ground

Sensing & Control

Beacon Detection Circuit:

  • Low-pass and high-pass filters remove ambient light and noise
  • Non inverting gain of 11 for amplification
  • Comparator with hysteresis squares signal for input capture

Encoder Motion Control:

  • PI control for setting motor speeds
  • Straight driving even with disturbances
  • Pulse counting for turn distances

Line Following:

  • 5 sensor analog array for navigation feedback
  • All sensors (especially inner 3): P control for line following
  • Outer 2 sensors: Also digital inputs for junction detection

Actuation Systems

DC Motors:

  • Drive brake configuration (1 PWM pin + 1 digital output)
  • Integrated motor driver PCBs from PDB rail (provided)
  • Conveyor motor: on/off mode

Servo Control:

  • All servos connected to Follower PIC
  • Shared period and timer with separate OC modules
  • Position servos: ball dispensing, arm, field indicator
  • Continuous rotation servo: ball collector

Software Architecture

Dual-PIC Event-Driven Framework:

Two PIC32s run independent ME 218 ES framework instances. Services (state machines) run cooperatively, with hardware ISRs capturing encoder pulses, IR beacon, SPI.

Leader PIC Responsibilities:

  • Navigation + logic state machine (NavTestSM) with 20+ states
  • Motor HAL: PWM, PI speed control, encoder counting
  • Line following control loop
  • IR beacon detection and determining field side
  • SPI polling of Follower (every 10ms)
  • Game timer management (138s)

Leader State Machine Flow

Follower PIC Responsibilities:

  • Top level FSM (4 states)
  • Ball collection state machine (scooper servo, conveyor motor)
  • Follower Motor Library: Conveyor, servos, arm
  • SPI: interrupt-driven command reception and response
  • Flag indicator servo (blue/green field side signaling)
  • Door servo actuation (dispense gates)

Follower State Machine Flow

Key Logic Systems:

Field Side Determination:

  • Robot turns left while ISR monitors beacon pulses
  • Four consecutive inter-pulse intervals classified by majority vote
  • BEACON_LEFT = green; BEACON_RIGHT = blue
  • SPI command to Follower to actuate field indicator servo

Line Following Control:

  • PD controller at 200 Hz
  • Three inner sensors: Error = 1000 * (right - left) / sum
  • Correction = Kp * error + Kd * d(error)/dt, clamped to ±8 RPM

Ball Collection:

  • Conveyor belt DC motor turned on
  • Scooper cycles through timed forward spin / stop intervals
  • After 16 ball cycles, system stops

SPI Communication:

  • Leader polls Follower every 10ms
  • Single-byte, full-duplex transfers
  • Follower pre-loads response after processing previous command
